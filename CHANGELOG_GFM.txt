### Version 2026.10.18.01.41 <sub>*(10/18/2026)*</sub>

#### Menus
* Changed where menus open: beside their window, on the side with the most room where the
  whole menu fits, so they stay on screen.
* Fixed submenus opening off screen: they now open on the left when there is no room on
  the right.
* Fixed controller focus leaving the visible part of a menu. Moving past the last or first
  visible row now scrolls the menu along.

#### Controller & Console
* Added a <kbd>shared controller layer</kbd>: one add-on window has the buttons at a time,
  opening another takes them over, and closing it hands them back to the window used before.
  Buttons the window does not use go to the game, and dialogs always get theirs.
* Added <kbd>controller button hints</kbd> that wrap without overlapping, follow the
  window while it is resized, and draw just above the add-on's own windows so window text
  never covers them.
* Fixed keys in <kbd>LibAPH</kbd>'s own layer firing while a dialog is on screen. They now
  give way, so text fields can always be selected and typed in.
* Fixed the hint text in empty edit boxes on console, which now uses the <kbd>gamepad
  font</kbd>.

#### Status Line & Memory Display
* Added a <kbd>one-line status text</kbd> for the top right of the screen or under another
  control such as the <kbd>compass</kbd>, where lines from several add-ons stack instead of
  overlapping.
* Added a display of <kbd>Lua and add-on pool memory</kbd> at the top right, on PC and
  console.
* Fixed <kbd>Cyrillic and Japanese</kbd> text not showing in the <kbd>status window</kbd>,
  which now uses the game's font faces.

#### Memory Cleanup
* Added a low-memory callback on console, fired when the game warns that add-on memory is
  low, plus a check of how close the add-on memory is to its limit.
* Added a <kbd>shared low-memory rescue</kbd> on console: it cleans in small steps every
  frame until add-on memory is back under 65% of the limit, adds a <kbd>Deep Clean</kbd>
  above 80% when the steps fall behind, and keeps going in combat. Only the add-on that
  calls it starts it, and a second add-on joins the running one.
* Updated cleanup results to say why the cleanup ran (for example "lowmem" for the
  console's <kbd>Low Add-On memory warning</kbd>).

#### Saved Data
* Added packing for <kbd>long number lists</kbd> in saved data, which makes them several
  times smaller.
* Added seals for <kbd>finished results</kbd>, so a number edited in the saved file shows
  as changed.
* Added crash copies, which keep <kbd>unfinished work</kbd> through a <kbd>crash or
  disconnect</kbd> and tell the add-on on the next load what cut it off.

#### Text & Graphs
* Added text fitting: <kbd>wrap text to fit</kbd>, shrink one-line text until it fits, and
  keep text above <kbd>graph lines</kbd>.
* Improved list rows and <kbd>search results</kbd>, which shrink their font instead of
  cutting off long names.
* Added graphs, drawn from <kbd>pooled pieces</kbd>, with round axis steps and time ticks.

#### Game Settings & Travel
* Added <kbd>FPS cap</kbd> controls that read and set the cap and keep <kbd>Limit
  Background FPS</kbd> and <kbd>Idle Power Reduction</kbd> off while an add-on measures.
* Added a count of running add-ons and libraries.
* Added house travel: a list of <kbd>houses to travel to</kbd>, and a jump with a callback
  when it fails.

#### Settings Menu
* Added the <kbd>settings panel</kbd> as a menu (checkboxes, choices, typed numbers,
  buttons that ask first) for players without the settings libraries.

#### Technical Style & Logic
* Improved work spread over frames. It stops before the game's <kbd>per-frame add-on CPU
  limit</kbd> on every platform that has one, and slows down while the add-on memory pool is
  nearly full.
* Added a time-left check for long steps, so one large piece of work no longer runs past
  the limit.
